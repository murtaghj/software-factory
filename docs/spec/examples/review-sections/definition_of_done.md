# Definition of done

All four criteria must pass the seven planned scenarios and the affected regression/contract matrix on the exact integrated candidate. Canonical test integrity, expected scenario counts and verifier provenance must pass. Enhanced assurance also requires independent oracle acceptance before implementation and a passing fresh adversarial evaluation of the exact candidate.

Peer plan approval and code review must be current; blocking findings must be resolved. Update the API/runbook notes. Reconcile required human PR approvals on the exact head, then publish an outcome manifest and recorded resource cleanup/ownership. Implementation checkboxes alone cannot establish completion; DoD D1–D7 provide the evidence mapping.
